Datenschutz

1. Datenschutz auf einen Blick

Der Schutz deiner persönlichen Daten ist uns wichtig. Wir behandeln personenbezogene Daten vertraulich und entsprechend der gesetzlichen Datenschutzvorschriften (DSGVO) sowie dieser Datenschutzerklärung.

2. Datenerfassung in dieser App

Server-Log-Files: Beim Aufruf der App verarbeitet der Hosting-Anbieter technisch bedingt Informationen in Server-Log-Dateien (z. B. Browsertyp, Referrer-URL, Uhrzeit der Anfrage). Diese Daten sind nicht bestimmten Personen zuordenbar.

Kartenkacheln: Auf Karten- und Detailseiten lädt die App Kartenkacheln von OpenStreetMap zur Laufzeit nach. Dabei wird deine IP-Adresse an die Server von OpenStreetMap übertragen.

Keine Cookies, kein Tracking: Diese App setzt keine Analyse- oder Trackingdienste ein und verwendet keine Cookies.

Keine persistente Speicherung im Browser: Favoriten werden nur flüchtig im Arbeitsspeicher gehalten und nicht in localStorage oder sessionStorage gespeichert.

3. Hosting auf GitHub Pages

Die App wird auf GitHub Pages bereitgestellt. Dabei können technisch notwendige Zugriffsdaten verarbeitet und in Protokolldateien gespeichert werden. GitHub kann dabei Dienstleister und Server außerhalb der EU einsetzen.

4. Deine Rechte

Du hast jederzeit das Recht auf Auskunft über Herkunft, Empfänger und Zweck der gespeicherten personenbezogenen Daten sowie ein Recht auf Berichtigung oder Löschung dieser Daten.
