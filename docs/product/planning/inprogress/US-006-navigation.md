# User Story 006 - Navigation

Die Navigation soll überarbeitet werden. 
Wenn die Darstellung auf einem mobilen Device erfolgt (nicht im Desktop Modus), soll die Navigation zwischen Seiten "Kalender", "Ensembles" und "Spielstätten" als komprimiert als Burger-Navigation angezeigt werden. 
Außerdem soll die Anzeige für die MÖglichkeit zwischen den Monaten zu blättern, auf die Zeichen '<' und '>' eingegrenzt werden. Dadurch wird die Zeile in der der Monat angezeigt wird, nicht mehr umgebrochen.
