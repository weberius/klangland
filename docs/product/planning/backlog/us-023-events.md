# User Story 023 - Umgestaltung Events

Die Seite 'events' soll umgestaltet werden, um mehr Information und eine bessere Übersichtlichkeit zu gewährleisten.

Die Box 'Programm' soll an oberster Stelle der Boxen angezeigt werden, wenn es in der mobilen Ansicht angezeigt und links oben, wenn die Webapp in der Desktop Ansicht dargestellt wird. 

Vor dem Programm soll die Deskription aus den events.json angezeigt werden. Darunter folgt dann das Programm selber

Nach dem Programm werden die Mitwirkenden angezeigt. In der Deskotp Ansicht bedeutet das, dass die Box rechts oben angezeigt wird. 

Nach den Mitwirkenden wird der Veranstaltungsort angezeigt. Die Informationen des Veranstaltungsortes umfasst aktuell den Namen des Ortes, die Stadt und den Link auf die Webseite der Spielstätte. Zusätzlich sollte die Adresse angezeigt werden. 

Es sollte einen Button geben, der einen Dialog öffnet und anbietet, auf eine Kartenapplikation der Wahl weiterzuleiten, um sich z.B. Routen zu lassen. Hier sollte auch der Hinweis stehen, das Benutzer:innen damit das Angebot verlassen. Ich bin mir hier nicht sicher, ob das Platformübergreifend machbar ist. Wenn nein, dann kann dieses Feature fallen gelassen werden.

Unterhalb des Veranstaltungsortes wird eine kleine Karte angezeigt, die auf den Veranstaltungsort einzoomt. In der mobilen Ansicht wird die Karte als letztes angezeigt. In der Desktop-Ansicht wird eine vierte Box rechts unten angezeigt.
