# User Story 015 - Kein Ticket Link für vergangene Daten

Die Eventseite zeigen, wenn die Information zum Zeitpunkt des Ingest vorhanden war, eine Link um Tickets kaufen zu können. Wenn das Event in der Vergangenheit liegt, soll dieser Link nicht angezeigt werden. Der Verweis auf die Tickets soll nur dann erfolgen, wenn es vom Datum her noch Sinn macht, Tickets zu kaufen.
