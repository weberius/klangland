# User Story - Werke

Neben den Ensembles, Spielstätten und dem Kalender, sollen auch die Werke auf einer eigenen Seite dargestellt werden. Die Route ist hier `/works`. Für die Werke wird ein Navigationspunkt zu der Hauptnavigation hinzugefügt werden.  

Die Darstellung ähnelt der von den Venues. D.h. jedes Werk ist in der Übersicht durch eine Kachel repräsentiert. Die Kacheln sind alphabetisch sortiert. Wenn ich auf das Werk klicke, wird eine Detailseite geöffnet mit weiteren Informationen zum Werk. Außerdem ist eine Liste vorhanden, von Veranstaltungen (events), auf denen die Werke gespielt werden.
