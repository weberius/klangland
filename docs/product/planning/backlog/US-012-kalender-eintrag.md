# In Kalender eintragen

Auf jeder Event-Seite soll die Möglichkeit bestehen, das Konzert per Klick in den Kalender einzutragen. Dafür werden sowohl Lösungen für iOS/ MacOs, Android, Windows implementiert und je nach verwendetem Browser zur Verfügung gestellt.

Außerdem soll es möglch sein, Events zu markieren, um später darauf filtern zu lassen. Der Filter kann als Link zum Kopieren zur Verfügung gestellt werden. Es gibt aber kein System ausserhalb der Webanwendung, das die Favoriten speichert, sodass z.B. durch einen Anmeldung, konkret diese Favoriten wieder angezeigt werden. Wenn also die Seite neu geladen wird, bzw. die Session abhanden kommt, gehen die Informationen verloren.

Dieser Umstand muss mit einem Dialog erklärt werden, wenn jemand auf den Button Tickets klickt.
