# User Story 014 - Link auf Wikipedia Artikel zum Orchester

Die Seite eines Orchesters zeigt zur Zeit grundlegende Informationen zum Orchester. 
Die Darstellung soll mit Informationen aus der Wikipedia erweitert werden. Diese bestehen einerseits aus der Kurzfassung des Artikels zum Orchester und dem Link zum Artikel auf der Wikipedia.

Die Kurzfassung des Artikels besteht aus einer Zusammenfassung des Wikipedia-Artikels auf 60 Wörter. Darunter folgt die Attributierung des Artikels. Ein Link ermöglicht es den kompletten Artikel zu lesen.
