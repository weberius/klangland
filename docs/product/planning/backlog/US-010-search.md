# Suche 

Es soll eine Suche implementiert werden.
Die Suche wird mit in der oberen Leiste in Form einer Text-Eingabe zur Verfügung gestellt. Sie steht auf jeder Seite zur Verfügung. Die Suche erfolgt über alle Daten (data-Objekt im Verzeichnis /data). Es ist möglich eine Fuzzy-Suche zu ermöglichen. Auf diese Weise kann z.B. 'Beethoven' gefunden werden, wenn 'bethoven' eingegeben wurde.
